# Interactive Food Safety & Geospatial Analytics Dashboard

An end-to-end Python-based data application designed to visualize, map, and analyze historical food poisoning incidents and public health risk factors across various regions of Morocco.

## Key Features
* **Geospatial Mapping:** Interactive map interface showcasing incident distribution, regional disparities, and hot-spots to help drive preventative health measures.
* **Risk Factor Analytics:** Graphical breakdowns analyzing root causes of contamination (e.g., hygiene practices, poor storage conditions, and water quality).
* **Dynamic Query Filtering:** Built-in dashboard components allowing users to filter analytical trends by regional demographics, specific time periods, and restaurant sectors.

## Data & Insights Source
* Integrated structured public health indicators, regulatory inspection insights from safety agencies (ONSSA), and analytical tracking data to form a cohesive reporting database.

## Tech Stack
* **Language:** Python
* **Web Framework:** Dash (by Plotly)
* **Data Engineering:** Pandas (Time-series aggregation & geospatial data cleaning)
* **Visualization:** Plotly Express / Plotly Graph Objects
* **Concepts:** Geospatial Analytics, Public Health Data Systems, BI Dashboard Engineering
